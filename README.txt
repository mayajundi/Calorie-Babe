# Macroly Phone App (PWA)

This folder is an installable Progressive Web App.

## Important
To install it on a phone, it must be opened from a secure HTTPS website.
Opening index.html directly from your computer is fine for testing, but installation/offline mode requires hosting.

## Easiest way to publish
Upload the contents of this folder to any static web host (for example Netlify, Vercel, GitHub Pages, or your own HTTPS website).

After it is live:
- iPhone/iPad: open the URL in Safari → Share → Add to Home Screen.
- Android: open the URL in Chrome → browser menu → Install app / Add to Home screen.

Your food library and daily data are stored locally on that device/browser.
